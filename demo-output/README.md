# EduNova Demo Output

This folder contains a quick GitHub-ready demo reel for the EduNova student learning platform.

## Files
- `edunova-demo.html` — autoplaying browser demo reel with 3 polished slides highlighting the landing page, dashboard, and outcomes.

## How to use
1. Open the HTML file in a browser.
2. Use browser dev tools or a screen recorder to capture a short clip.
3. Export the final result as MP4 or GIF for GitHub/portfolio use.

## Highlights included
- Landing page with course and feature messaging
- Dashboard overview with progress tracking
- Certificate and student outcomes messaging

## Suggested recording flow
- 5–8 second capture for the landing page
- 5–8 second capture for the dashboard/feature slide
- 5–8 second capture for the outcomes/certificate slide
- Keep the final output under 20–30 seconds for GitHub social sharing

## Project context
This demo is based on the project pages in the `frontend/` folder, including the home page and dashboard design.
